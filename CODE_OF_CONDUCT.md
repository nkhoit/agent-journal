# Code of Conduct

## Our pledge

We want a welcoming, respectful, and technically rigorous community. Participants should be able to contribute without harassment, discrimination, intimidation, or retaliation.

## Expected behavior

- Be respectful and assume good faith while discussing technical trade-offs.
- Critique ideas and code, not people.
- State uncertainty and evidence clearly, especially for security and delivery claims.
- Protect private information and do not publish credentials, private topology, or sensitive journal content.
- Accept correction and make space for different experience levels.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, doxxing, impersonation, deliberate exposure of secrets, malicious code or documentation changes, and sustained disruption of project work are not acceptable.

## Enforcement

Report concerns privately through the security or maintainer contact configured in the repository hosting settings. Maintainers may remove content, restrict participation, or take other proportionate action. Reports will be handled as confidentially as practical. Retaliation against a good-faith report is prohibited.

This code is adapted from the Contributor Covenant spirit and applies to project spaces and interactions representing the project.
